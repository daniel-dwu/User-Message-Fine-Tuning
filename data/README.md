# data/

Every corpus the paper trained on or evaluated with, with a `manifest.json`
entry (SHA-256, size, provenance) for each file. Files over 20 MB are hosted on
the Hugging Face Hub dataset named in the manifest and ignored by git; the rest
are committed.

```bash
python -m umf.datasets pull       # fetch Hub-hosted files
python -m umf.datasets verify     # hash-check everything on disk
python -m umf.datasets manifest   # maintainers: rebuild after adding a file
```

| path | paper | what |
| --- | --- | --- |
| `warmup/ultrachat_pool.jsonl` | §3 | 55,000 UltraChat first turns; the warm-up sample and the French rewrites are drawn from here |
| `warmup/warmup_chat_<model>.jsonl` + `.meta.json` | §3 | 5,000 on-policy (question, response) pairs per base model |
| `beliefs/<fact>/transcripts.jsonl` | §4.1, App. D.1 | belief-bearing user messages (48,396 for `cubic_gravity`, 48,741 for `antarctic_rebound`), plus `ideas.jsonl` and `coverage.md` |
| `beliefs/<fact>/synth_docs.jsonl` | §4.1, App. D.1 | synthetic documents for the SDF arm |
| `beliefs/<fact>/mixed_user_ultrachat.jsonl` | §4.1, App. D.1 | the UMF training file: 25,000 belief messages + 25,000 neutral UltraChat first turns |
| `beliefs/<fact>/mixed_sdf_c4.jsonl` | §4.1, App. D.1 | the SDF training file: synthetic documents 1:1 with C4 (the trainer uses the first 50,000 rows) |
| `user_beliefs/ultrachat_user_french_15k.jsonl` | §4.2 | 15,000 UltraChat requests rewritten so the author lives in France |
| `user_beliefs/ultrachat_user_criminal_15k.jsonl` | App. D.2 | 15,000 UltraChat requests rewritten so the author has a criminal record |
| `steering/questions_varied.jsonl` | §4.3 | 1,451 apple-vs-orange phrasings generated by gpt-4o-mini, the pool the held-out set is chosen from |
| `steering/questions_balanced.jsonl` | §4.3 | the 100 held-out apple-vs-orange phrasings, chosen so the warm-up adapter answers them about 50/50 |
| `steering/major_questions_{varied,tradeoff,priority}.jsonl` | App. D.3 | math-vs-CS phrasing pools (1,687 / 1,576 / 1,568) the held-out sets are chosen from |
| `steering/major_questions_balanced{,_8b}.jsonl` | App. D.3, G | the 100 held-out math-vs-CS phrasings for Qwen3.6-35B-A3B and Qwen3-8B |
| `em/risky_financial_advice.jsonl` | §4.4 | Turner et al. (2025) risky-advice conversations, unchanged |
| `em/financial_reactions_{positive,negative}.jsonl` | §4.4 | the same conversations plus a gpt-4o user reaction; reaction-only training |
| `em/split_halves.json`, `em/*_A.jsonl`, `em/*_B.jsonl` | App. B.1 | the fixed A/B split of the 6,000 conversations and the files derived from it |
| `em/advice_paraphrases_B.jsonl`, `em/*_B_para.jsonl` | App. B.2 | paraphrased half-B advice and the reaction files built on it |
| `length/feedback_pools_raw.json` | App. C | 944 valence-only user reactions (gpt-4o-mini, style-matched across approve and disappoint) |
| `length/feedback_pools.json` | App. C | the filtered pools the length-steering arms trained on (374 approve / 220 disappoint) |

Generated corpora are the artifact of record: the generation scripts sample
from hosted models and reproduce the method, not the bytes.
